# Division DS: tokens

> Components and screens use semantic and component tokens only, as var(--name). Primitive colour ramps (--color-<ramp>-<stop>) are the raw material the semantic layer is built from, not a palette to pick from.

Write a token as a CSS variable inside a Tailwind arbitrary value: `bg-[var(--color-surface-base)]`, `text-[var(--color-text-primary)]`, `gap-[var(--spacing-4)]`. You must use only the names listed here. Do not make one up: an undefined variable is not an error in the browser, it just paints nothing.

## Semantic colour

Choose by what the colour is doing, not by how it looks. Values differ by theme and switch on their own.

| Token | Use | Value |
|---|---|---|

| `--color-surface-sunken` | The opaque fill of a control you type or pick in (Input, Textarea, Select), and of small opaque surfaces: Kbd, Tag, Tooltip, menus, toasts. Not a card. | `dark #0d1016, light #c2cddc` |
| `--color-surface-raised` | The translucent fill of a Card or panel sitting on the page. Use the Card component; do not paint it by hand, and avoid nesting raised inside raised. | `dark rgba(40, 52, 69, 0.42), light rgba(255, 255, 255, 0.6)` |
| `--color-surface-scrim` | The dimming layer behind a Dialog, Sheet or CommandPalette. Those components paint it; nothing else should. | `dark rgba(0, 0, 0, 0.6), light rgba(11, 14, 19, 0.48)` |
| `--color-border-hairline` | A quiet divider or panel edge that carries no information: row separators, card outlines. | `dark rgba(214, 226, 240, 0.16), light rgba(11, 14, 19, 0.12)` |
| `--color-border-hairline-strong` | A stronger decorative rule: table header underlines, section rules. Still decorative, never the only sign of a control. | `dark rgba(214, 226, 240, 0.32), light rgba(11, 14, 19, 0.22)` |
| `--color-border-control` | The boundary of an interactive control at rest (Input, Select, secondary Button). The one border that has to be seen to find the control. | `dark #646b72, light #616874` |

## Component

What the controls are built from. Use the component; reach for these only when building a new control.

| Token | Use | Value |
|---|---|---|
| `--component-control-height-sm` | Height of a small control (32px): a compact Button, an Input in a dense row. | `32px` |
| `--component-control-height-md` | Height of a default control (40px). What Button, Input and Select use unless told otherwise. | `40px` |
| `--component-control-height-lg` | Height of a large control (48px): the main action of a page or a touch-first form. | `48px` |
| `--component-control-border-rest` | A text control's border at rest. Set by Input, Textarea and Select. | `var(--color-border-control)` |
| `--component-control-border-hover` | A text control's border under the pointer. | `var(--color-text-muted)` |
| `--component-control-border-invalid` | A control's border when its field has an error. Set through the invalid prop, which FormField passes. | `var(--color-accent-hostile-text)` |
| `--component-control-border-selection` | The border of Checkbox, Radio and Switch at rest. | `var(--color-border-selection)` |
| `--component-control-border-selection-hover` | The border of Checkbox, Radio and Switch under the pointer. | `var(--color-text-secondary)` |
| `--component-control-border-disabled` | A disabled control's border. | `var(--color-border-control)` |
| `--component-control-indicator-checked` | The colour of a selection control in its chosen state: a checked Checkbox, a selected Radio, an on Switch. | `var(--color-accent-signal-text)` |
| `--component-control-progress-fill-ok` | A Progress bar's fill at tone ok. | `var(--color-accent-ok-text)` |
| `--component-control-progress-fill-warning` | A Progress bar's fill at tone warning. | `var(--color-accent-warning-text)` |
| `--component-control-progress-fill-hostile` | A Progress bar's fill at tone hostile. | `var(--color-accent-hostile-text)` |
| `--component-control-fill-rest` | A text control's fill. | `var(--color-surface-sunken)` |
| `--component-control-fill-disabled` | A disabled control's fill. | `var(--color-surface-raised)` |
| `--component-control-text-rest` | The text typed into a control. | `var(--color-text-primary)` |
| `--component-control-text-placeholder` | A control's placeholder text. | `var(--color-text-placeholder)` |
| `--component-control-text-disabled` | A disabled control's text. | `var(--color-text-muted)` |
| `--component-button-primary-fill` | The primary Button's fill. Use the Button; do not rebuild it. | `var(--color-accent-signal-fill)` |
| `--component-button-primary-text` | The primary Button's label. | `var(--color-accent-signal-ink)` |
| `--component-button-danger-fill` | The danger Button's fill. | `var(--color-accent-hostile-fill)` |
| `--component-button-danger-text` | The danger Button's label. | `var(--color-accent-hostile-ink)` |

## Spacing

Tailwind's own spacing utilities sit on the same 4px grid (`gap-3` is 12px, `p-4` is 16px) and are fine to use.

| Token | Use | Value |
|---|---|---|
| `--spacing-1` | 4px. The gap between an icon and its label, or two tightly bound marks. | `4px` |
| `--spacing-2` | 8px. The gap between related items in a row: chips, a label and its value. | `8px` |
| `--spacing-3` | 12px. The gap between sibling controls, such as two buttons. | `12px` |
| `--spacing-4` | 16px. Default padding inside a control or a compact panel; the gap between fields. | `16px` |
| `--spacing-6` | 24px. Padding inside a Card; the gap between groups in a form. | `24px` |
| `--spacing-8` | 32px. The gap between blocks within a section. | `32px` |
| `--spacing-12` | 48px. The gap between sections of a page. | `48px` |
| `--spacing-16` | 64px. The page gutter from the large breakpoint, and the gap around a hero block. | `64px` |

## Motion

| Token | Use | Value |
|---|---|---|
| `--duration-fast` | 120ms. Hover and press feedback: colour and border changes on a control. | `120ms` |
| `--duration-base` | 180ms. The default for anything that is not hover feedback: a menu or tooltip entering, a collapse. | `180ms` |
| `--duration-slow` | 320ms. A larger change: a section expanding, a progress bar filling, the Switch thumb settling into shape after it arrives. | `320ms` |
| `--duration-stepped` | 180ms, run in steps. The Button's stepped hover arrival. Used by .transition-stepped only. | `180ms` |
| `--ease-snap` | The default easing curve: quick out, soft landing. Use it for every transition that is not a physical object changing shape. | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| `--ease-accelerate` | Starts slow, gathers speed and stops at the end. For a small object that travels into a boundary and gives slightly against it (the Switch thumb). Not for anything that should land softly: that is --ease-snap. | `cubic-bezier(0.4, 0, 1, 1)` |

## Primitive ramps

Not for use in components or screens: `--color-signal`, `--color-hostile`, `--color-ok`, `--color-info`, `--color-warning`, `--color-neutral`, each with stops from 50 to 950. The semantic layer is built from them.
