# Division DS: design

> A React 19, Tailwind 4 and Radix design system: 68 components, design tokens in three layers, light and dark themes, WCAG 2.2 AA. This file is the system in one page; each component links its full page with props and examples.

Links are relative to this file. Generated by `npm run agent-docs`.

## Colour

Components and screens use semantic and component tokens only, as var(--name). Primitive colour ramps (--color-<ramp>-<stop>) are the raw material the semantic layer is built from, not a palette to pick from.

Write a token as a CSS variable: `bg-[var(--color-surface-base)]`. Use only the names below. Component tokens and the full list: [llms-tokens.txt](llms-tokens.txt).

## Motion

| Token | Use | Value |
|---|---|---|
| `--duration-fast` | 120ms. Hover and press feedback: colour and border changes on a control. | `120ms` |
| `--duration-base` | 180ms. The default for anything that is not hover feedback: a menu or tooltip entering, a collapse. | `180ms` |
| `--duration-slow` | 320ms. A larger change: a section expanding, a progress bar filling, the Switch thumb settling into shape after it arrives. | `320ms` |
| `--duration-stepped` | 180ms, run in steps. The Button's stepped hover arrival. Used by .transition-stepped only. | `180ms` |
| `--ease-snap` | The default easing curve: quick out, soft landing. Use it for every transition that is not a physical object changing shape. | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| `--ease-accelerate` | Starts slow, gathers speed and stops at the end. For a small object that travels into a boundary and gives slightly against it (the Switch thumb). Not for anything that should land softly: that is --ease-snap. | `cubic-bezier(0.4, 0, 1, 1)` |

## Rules

In full: [llms-guidelines.txt](llms-guidelines.txt).

- **Imports.** Import a component from its own file, by relative path.
- **Colour.** Every colour is a semantic token inside a Tailwind arbitrary value: `text-[var(--color-text-primary)]`, `bg-[var(--color-surface-base)]`.
- **Providers.** One `<Toaster>` and one `<TooltipProvider>` sit at the root of the app (`AppShell`, `DemoLayout` in this repository).
- **Focus.** Anything focusable that you style yourself gets `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--color-focus-ring)]`.
- **Page title, empty, loading.** Plan these before writing a screen.
- **What the system does not have.** No Popover, no Combobox (single value: use `Select`; several: `MultiSelect`), no date picker.
- **Vocabulary.** Inside this repository, `npm run check:vocabulary` bans a list of words in `src/`, `scripts/` and `e2e/` (the list is `scripts/lib/vocabulary.mjs`; it is not published with the docs).
- **Fill, text, ink.** Each accent has three roles.
- **Status tones.** `ok` done or healthy; `warning` degraded or needs attention; `hostile` failed or destructive; `info` in progress or neutral news; `signal` brand emphasis (a sale, the selected thing); `neutral` inactive.
- **Themes.** The theme is `data-theme="light"` or `"dark"` on `<html>` (`src/lib/theme.ts`); dark is the default.
- **App navigation.** A few views: `Navbar` (`current: true` on the open one).
- **Type.** Three families, as utilities: `font-display` (headings, figures), `font-body` (the default, set by the shell), `font-mono` (labels, code, tabular numbers).
- **Text size.** Secondary text is 14px or larger.
- **Cards.** To highlight or select a `Card`, set the border inline with a token: `style={{ border: '2px solid var(--color-accent-signal-fill)' }}`.
- **Links.** Components that render links take `renderLink`, defaulting to a plain `<a>`.
- **Charts and bundle size.** `ChartPanel` and `Sparkline` bring in recharts, a few hundred kB.
- **Forms.** In a form, `Input`, `Textarea`, `Select`, `MultiSelect` and `QuantityStepper` go inside a `FormField`, which supplies the label, help and error and keeps an `id` you pass to the control.
- **Buttons.** Two or more buttons side by side need a parent with a gap (`flex flex-wrap gap-3`); `DialogFooter` and `CardFooter` already are one.
- **Icon-only buttons** are `IconButton` with a required `label`.
- **Overlays.** A task on top of the page is a `Dialog`; a destructive confirm is `AlertDialog`, not `Dialog`; filters, navigation on a narrow screen or one item's detail beside a list is a `Sheet`.
- **Feedback.** A `Toast` confirms something the person just did and then leaves, so it never holds the only copy of anything; a message that must stay is an `Alert` in the page.
- **Motion.** The components animate themselves, and the shell animates a route change.
- **Assistant copy.** A button names the action ("Summarize"), never "AI".
